# DR - Director (PWA)

شات بوت يتحقق من أمان الدواء أثناء الحمل من عدة مصادر، ويحفظ النتيجة في قاعدة البيانات.

## التشغيل
1. انسخ المجلد إلى سيرفر PHP 8+ (مع cURL و PDO MySQL) على HTTPS (شرط الـ PWA).
2. أنشئ القاعدة: `mysql -u root -p < schema.sql` (الجدول أيضاً يُنشأ تلقائياً لو القاعدة موجودة).
3. عدّل بيانات الاتصال في `config.php`.
4. افتح `index.html` من المتصفح ثم "تثبيت التطبيق".

## المنطق
- المصادر: نشرات FDA (حتى 5 نشرات، كل نشرة صوت) + Lexicomp Online (يتطلب Cookie جلسة في `config.php` ← `lexi`) + RxList (`config.php` ← `drugs`).
- كل مصدر يُصنَّف: متعارض / غير متعارض / محايد.
- غير متعارض > متعارض → "آمن علي الحمل" | العكس → "غير آمن علي الحمل" | التساوي → "استشر الطبيب".
- `strict_mode` في config.php: لو أي مصدر قال "ممنوع/Category X" لا تظهر "آمن" أبداً.
- أي سؤال متكرر عن نفس الدواء يُجاب من جدول `drug_checks`، وزر "تحديث البيانات" يعيد البحث.
- الأسماء العربية تُحوَّل للإنجليزية عبر ويكيبيديا؛ لو فشل التحويل يُطلب الاسم بالإنجليزية.

## إضافة مصدر جديد
أضف رابطه داخل `analyze()` في api.php ثم مرر نصه إلى `classify()`.

## Lexicomp
- `lexi.enabled=false` يعطّل المصدر. الـ `cookie` ينتهي بانتهاء الجلسة — جدّده من المتصفح (F12 → Network → Headers → Cookie) وحطه في `config.php`.

## RxList
- بدون تسجيل دخول. يجرّب `rxlist.com/{drug}-drug.htm` ثم `/generic-drug.htm` ثم `/search/rxl/{term}` كحل أخير.
